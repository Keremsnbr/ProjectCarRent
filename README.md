# Project Car Rent

## 🚗 About the Project
This project provides a system where users can perform car rental operations. The project is designed using object-oriented programming (OOP) principles such as **Polymorphism** and **Inheritance**. It also includes a **user authentication system** to ensure users can securely log in to the system.

## 📌 Features
- **User Authentication System**: Users can log in to the system with a correct username and password.
- **Car Rental**: Users can rent cars based on specific criteria.
- **Pricing**: Rental pricing is calculated based on the duration (day/hour).
- **Polymorphism and Inheritance**: Cars are represented through classes for different types of vehicles (e.g., luxury cars), and inheritance is used to promote code reusability across different car types.
- **Balance System**: Users can log in with predefined balances and can add funds to their accounts.
- **Multiple User Support**: Multiple users can register in the system and perform different rental operations.

## Technologies Used
- **Java** (Primary programming language)
- **OOP Principles** (Encapsulation, Polymorphism, Inheritance)
- **User Authentication System**
